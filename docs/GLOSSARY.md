# 용어집 (opex-app)

화면·버튼·안내문·오류 메시지·메일 문구·문서에서 쓰는 말을 한 가지로 맞춘 기준이다. 사람이 읽는 글자에만 적용하며, 코드 식별자·DB 저장 값(역할 코드 MEMBER/MANAGER/HQ/ADMIN, 감사 로그 action/entity 키, memberClaim 값 등)과 엑셀 양식(시트명·머리글·결제방법 값·정산표 라벨)은 바꾸지 않는다.

## 역할

| 용어 | 뜻 | 쓰지 않는 말 | 예 |
| --- | --- | --- | --- |
| 팀원 | 프로젝트에 속해 지출을 입력하는 사람 (역할 코드 MEMBER) | 직원, 사원, 구성원, 프로젝트 구성원 | "팀원 확인", "팀원별 내역", "프로젝트 팀원" |
| 프로젝트 PM | 프로젝트를 맡아 마감·상신하는 사람 (역할 코드 MANAGER). 역할 선택지·배지·권한 설명·역할표에서만 이 이름, 문장 안에서는 "PM" | 팀장(역할 뜻), 매니저 | "이 프로젝트 PM", "PM이 정합니다" |
| 재무 승인 | 상신된 달을 승인·반려하고 예산·기준 정보를 관리하는 역할 (역할 코드 HQ). 문장에서는 "재무 승인 담당" | 재무팀, 재무, 본사(역할 뜻) | "재무 승인 담당이 승인", "재무 승인 담당에게 요청" |
| 시스템 관리자 | 계정·조직도·접속 기록을 관리하는 역할 (역할 코드 ADMIN). 프로젝트 데이터는 조회 전용 | 관리자, 어드민 | "시스템 관리자에게 요청하세요", "시스템 관리 작업"(감사 구분) |
| 재무회계팀 | 실제 부서명. 이 부서 소속은 기본으로 재무 승인 권한을 받는다 | — | "재무회계팀 소속은 기본으로 재무 승인 권한입니다" |
| 조직장 | 부서별로 지정된 사람. 자기 조직과 하위 조직의 프로젝트를 조회·취합한다 | 부서장(역할 뜻) | "상위 PM·조직장 조회" |

결제방법·엑셀 양식·정산표의 "본사", "본사지출", "본사 집행내역"은 그대로 쓴다(역할이 아니라 지출 구분).

## 사람

| 용어 | 뜻 | 쓰지 않는 말 | 예 |
| --- | --- | --- | --- |
| 팀원 | 프로젝트에 속한 사람 | 직원, 구성원 | "팀원 지정", "팀원 미확인" |
| 사용자 | 로그인 계정 (시스템 관리자·조직도·로그인 화면에서만) | — | "사용자 계정", "비활성 사용자" |
| 임직원 | 조직도 화면의 회사 사람 | 조직원, 직원 | "임직원 추가", "모든 임직원이 조회" |
| 실제 사용한 사람 | 출입증을 실제로 쓴 사람 (외부인 처리 건) | 실제 사용자 | "실제 사용한 사람: 홍길동" |
| 연결 안 된 이름 | 업체 파일의 이름이 팀원과 연결되지 않음 | 직원을 찾지 못한 사용자 | "연결 안 된 이름 3개" |
| 이전 팀원으로 처리 | 프로젝트에서 빠진 사람 처리. 날짜를 가리키는 명사 "철수일"은 그대로 | 철수, 철수 처리 | "9/30에 이전 팀원으로 처리됨" |
| 인원 | 머릿수 | — | "대상인원 3명" |

## 기록·단계

| 용어 | 뜻 | 쓰지 않는 말 | 예 |
| --- | --- | --- | --- |
| 내역 | 기록 모음 | 명세, 목록(기록 뜻) | "지출 내역", "출입증 내역", "업체 내역", "이 달 출입증 내역" |
| 기록 | 접속·변경이 남긴 것 | 이력 | "접속·변경 기록" |
| 마감 → 상신 → 승인/반려 | 월 처리 단계 | 결재, 제출(상신 뜻) | "9월 상신", "반려하기", "승인 취소하기" |
| 입력 기한 | 팀원이 그 달 지출을 입력·수정할 수 있는 마지막 날 = 다음 달 3일 (지나면 PM이 대신 입력) | 제출 기한, 월말 | "입력 기한 10월 3일", "입력 기한까지 D-2" |
| 마감 대기 | 입력 기한이 지났는데 아직 마감하지 않은 달 (PM이 마감할 차례, 배지는 앰버) | 미마감, 작성중(이 뜻) | "9월 마감 대기 — 마감하세요" |
| 확정 | 출입증 월 확정에만 | 확정(승인·반려 대화상자 버튼), 확정(마감된 달의 지출 뜻) | "9월 출입증 확정", "확정 취소" |
| 마감분 / 작성중 | 차트·집행 현황에서 마감 이상인 달의 지출 / 아직 작성중인 달의 지출 | 확정(이 뜻) | 범례 "마감분 1,200,000원 · 작성중 300,000원" |
| 검토할 달 | 재무 화면에서 지금 처리할 달 | — | "검토할 달: 9월" |
| 소명 필요 | 규정 점검에 걸려 사유를 적어야 하는 건 | 확인 필요 | "소명 필요 2건" |
| 조회 전용 | 보기만 되고 바꿀 수 없음 | 읽기 전용 | "종료된 프로젝트는 조회 전용" |

## 출입증 부담

| 용어 | 뜻 | 쓰지 않는 말 | 예 |
| --- | --- | --- | --- |
| 회사 부담 | 업무 사용으로 인정되어 회사가 내는 것 (결정 OVERTIME) | 회사부담, 제외 인정 | "회사 부담 12,000원" |
| 본인 부담 | 사용한 사람이 내는 것 (결정 DEDUCT). 급여 공제는 괄호 보조로만 | 개인 부담, 개인부담, 개인 사용, 급여 공제(단독) | "본인 부담(급여 공제)", "회사 부담 12,000원 · 본인 부담 5,000원" |
| 업무 사용 | 팀원이 회사 부담을 요청하는 표시 (memberClaim=OVERTIME). 팀원이 하는 표시는 이것 하나뿐 — 표시 없음 = 본인 부담(기본값)이라 따로 확인하지 않고 줄마다 글자도 쓰지 않는다 | 제외 요청, 본인 부담 확인, 개인 사용 표시 | "업무 사용이 있으면 ○를 눌러 표시" |
| 출입증 | 업체가 보내 준 월 사용 내역을 정산하는 기능. 예시값 "고객사 출입증"은 그대로 | 업체 출입증 | "출입증 내역", "출입증 정산" |
| 표시 열 | 업체 파일에서 화면에 함께 보일 열 (예산 항목·지출 항목과 구분) | 표시 항목 | "표시 열 이름을 입력하세요" |
| 비고 | 출입증 엑셀의 자유 메모 열 | 메모, 사유·메모 | 엑셀 열 "비고" |

인사 전달 엑셀의 시트명("급여 공제 대상", "공제 상세")은 그대로 쓴다.

## 동사

| 용어 | 뜻 | 쓰지 않는 말 | 예 |
| --- | --- | --- | --- |
| 입력 | 지출을 적어 넣는 것 | 지출 추가, 지출 등록 | "지출 입력", "입력됩니다" |
| 등록 | 마스터·예산·변경계약을 새로 만드는 것 | — | "예산 등록", "항목 등록" |
| 올리기 | 파일을 보내는 것 | 업로드 | "업체 내역 올림", "다시 올리기" |
| 수정 | 저장된 기록을 고치는 것 | 정정, 편집 | "지출 수정" |
| 변경 | 설정·상태를 바꾸는 것 | — | "비밀번호 변경", "역할 변경" |
| 요청 | 다른 역할에게 처리를 부탁하는 것 | 문의 | "PM에게 요청하세요", "시스템 관리자에게 요청" |
| 대신 입력 | PM이 팀원 대신 지출을 입력하는 것 | 대리 입력 | "대신 입력: 김하늘" |
| 임시 비밀번호 발급 / 다시 발급 | 계정 비밀번호를 새로 주는 것 | 초기화, 재발급 | "임시 비밀번호 발급" |
| 삭제 | 기록을 지우는 것 (대화상자 본문). 입력칸 비우기 "지우기"는 그대로 | 지워집니다 | "삭제됩니다" |
| X 취소 | 한 행위를 무효로 돌리는 것 | X 해제 | "승인 취소", "확정 취소", "종료 취소" |
| X 해제 | 잠금·지정을 푸는 것 | X 취소 | "마감 해제", "보관 해제", "PM 해제", "잠금 해제" |
| 변경 취소 | 저장 전 편집을 버리는 것 (SaveBar) | 되돌리기 | 버튼 "변경 취소" |
| 되돌리기 | 저장된 것을 되돌리는 토스트 | — | 토스트 "되돌리기" |
